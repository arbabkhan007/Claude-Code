INTERIOR DESIGN PROJECT MANAGER — FEATURE REFERENCE
===================================================

PURPOSE
-------
A professional, reusable project-management workbook for interior designers,
decorators, stagers, design studios, and project coordinators. It manages a
project from client onboarding and product sourcing through purchasing,
delivery, installation, billing, and final punch-list completion.

FILE COMPATIBILITY
------------------
• Microsoft Excel: Native .xlsx format; no macros are required.
• Google Sheets: Import with File > Import > Upload > Create new spreadsheet.
• Editable/unlocked: All workbook content can be customized. No password is set.
• Formula compatibility: Standard formulas work in Excel and Google Sheets.
• Printable reports use FILTER, supported by current Excel and Google Sheets.
• Chart styling can vary slightly after importing into Google Sheets.

8. Finishes Schedule

14. Client Approvals

16. Task List

17. Measurement Log

18. Contractor Tracker

20. Project Notes

21–25. Printable Reports
    • Client-facing FF&E report

    • Vendor order report

26. Lists (hidden)

    • Can be unhidden and edited when customization is required.

PREMIUM AUTOMATION
------------------
• Dropdowns for rooms, categories, vendors, statuses, priorities, approvals,
  orders, deliveries, installation, damage checks, invoices, and payments.
• Named ranges connect room and vendor lists to related schedules.
• Formula cells use a blue tint; normal input cells are white.
• Automatic FF&E totals and final landed costs.
• Automatic room spending and remaining budget.
• Automatic budget difference, balance due, and totals.
• Automatic dashboard counts and percentages.
• Automatic overdue-task detection.
• Automatic pending-approval and open-order metrics.
• Automatic delivered-but-not-installed and not-ordered counts.
• 5 live dashboard charts.
• 5 dynamic printable reports.
• Conditional formatting:
  Green = complete, approved, paid, delivered, installed, or good condition
  Yellow = pending, in progress, review, sent, scheduled, waiting, or ordered
  Red = overdue, delayed, rejected, damaged, missing, wrong, or over budget
  Gray = cancelled, returned, or on hold
• Filters on all major schedules.
• Frozen header rows for easier navigation.
• Landscape print settings, repeated headers, and fit-to-page configuration.
• 250 prepared rows on most schedules and 100 timeline task rows.
• Macro-free and password-free.

SOURCE-CODE CUSTOMIZATION
-------------------------
The Python generator is create_interior_design_workbook.py.

Common changes:
• Change ROWS = 250 to increase or decrease prepared schedule capacity.
• Change OUT to select a different output filename/path.
• Edit NAVY, BLUE, TEAL, GREEN, YELLOW, RED, and GRAY to rebrand colors.
• Edit the lists dictionary to add dropdown choices.
• Edit sheet_order to change worksheet order.
• Update the Welcome-tab support placeholder before selling/distributing.

For reliable dropdowns and dashboard calculations, users should select standard
status values rather than typing variations. Keep a backup of the original
workbook before changing formula columns or worksheet names.
