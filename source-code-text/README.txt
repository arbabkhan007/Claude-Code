SOURCE CODE PACKAGE
===================

Files included:

1. interior_design_project_workbook_source.txt
   - Plain text copy of the Google Sheets Apps Script source code.
   - Paste this into Google Sheets > Extensions > Apps Script > Code.gs.

2. FEATURES.txt
   - Full text feature list for future product descriptions, documentation, or sales page copy.

Note:
Google Sheets automation uses Google Apps Script, which is JavaScript-based, not Python. For that reason, the working workbook-builder code is provided as a plain .txt source file and as the original .gs file.
