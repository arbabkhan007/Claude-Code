Premium Features
----------------
- Dropdown menus for rooms, vendors, categories, statuses, priorities, approvals, orders, delivery, installation, payment, project types, fixture types, finish types, trades, meetings, and more.
- Room dropdowns are linked to the Room List.
- Vendor dropdowns are linked to the Vendor & Supplier Database.
- Filters are applied to every major schedule/report tab.
- Frozen header rows.
- Header row warning protection to prevent accidental edits.
- Auto-formulas for total cost, final cost, remaining budget, budget variance, paid balance, overdue tasks, and dashboard totals.
- Conditional formatting colors:
  - Green = complete / approved / installed / paid / on budget
  - Yellow = pending / in progress / sent
  - Red = delayed / overdue / rejected / over budget
  - Gray = cancelled / on hold
- Chart-based dashboard.
- Printable reports for client, room budget, vendor orders, installation, and punch list.
- Hidden Lists sheet stores dropdown options cleanly.
- Works in Google Sheets and can be exported to Excel.

How To Use Source Code
----------------------
1. Open a blank Google Sheet.
2. Go to Extensions > Apps Script.
3. Paste the code from interior_design_project_workbook_source.txt into Code.gs.
4. Save the Apps Script project.
5. Run buildInteriorDesignProjectWorkbook().
6. Approve permissions.
7. The full workbook will be generated automatically.
8. Optional: download as Excel from File > Download > Microsoft Excel (.xlsx).

Fool-Proof / Safety Notes
-------------------------
- The script creates all sheets automatically.
- It resets the active workbook before rebuilding so duplicate tabs are avoided.
- Header rows are protected with warning-only protection, so users can still edit intentionally.
- Formula columns are auto-filled for 250 rows.
- Dropdown values are stored in a hidden Lists sheet.
- Major schedule tabs automatically receive filters.
- The workbook is editable and can be customized after generation.
- If Google chart placement looks different after Excel export, resize the charts manually in Excel.
