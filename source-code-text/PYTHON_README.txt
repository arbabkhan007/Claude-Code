PYTHON VERSION INSTRUCTIONS
===========================

File:
  interior_design_project_workbook.py

What it does:
  Creates a native Microsoft Excel workbook named:
  interior_design_project_workbook.xlsx

Requirement:
  pip install openpyxl

Run command:
  python interior_design_project_workbook.py

Important:
  Google Sheets scripts are normally written in Google Apps Script, not Python.
  This Python file is a separate Excel workbook generator. Use it when you want
  a native .xlsx file generated from Python.

Included safety features:
  - Missing dependency message if openpyxl is not installed
  - Creates sheets automatically
  - Adds dropdown validation lists
  - Adds formulas
  - Adds dashboard KPI formulas
  - Adds charts
  - Adds filters and frozen headers
  - Adds conditional formatting
  - Adds printable reports
