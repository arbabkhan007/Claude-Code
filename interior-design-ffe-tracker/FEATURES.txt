PURPOSE
-------
A professional multi-tab workbook for interior designers and home decorators
to manage full project lifecycle: client profile, rooms, FF&E schedule,
furniture/fixtures/finishes, sourcing, vendors, budget, purchase orders,
delivery & installation, client approvals, timeline, tasks, measurements,
contractors, invoices, meeting notes, and printable reports.

FF&E = Furniture, Fixtures & Equipment.

2. SHEET PROTECTION & FORMULA LOCKING
================================================================================
- Sheet protection password: premium
- Formula / calculated cells: LOCKED (cannot edit accidentally)
- Input / data-entry cells: UNLOCKED (still editable while sheet is protected)
- Headers, titles, labels, banners: LOCKED
- Soft-blue fill = locked formula
- Cream / gold fill = editable input
- Filters and sorting remain allowed under protection
- Insert/delete columns blocked; row insert allowed for data growth
- To fully unlock in Excel: Review → Unprotect Sheet → password: premium
- NOTE: Google Sheets does not fully honor Excel sheet protection the same way;
  full formula locking works best in Microsoft Excel.

26. AUTO-CALCULATIONS (FORMULAS)
================================================================================
Master FF&E:
  Total Cost  = Quantity × Unit Cost
  Final Cost  = Total + Tax + Shipping − Discount

Room List:
  Estimated Spend = SUMIF(FF&E by room, Final Cost)
  Actual Spend    = SUMIFS(FF&E by room, status <> Cancelled)
  Remaining       = Budget Allocation − Actual Spend

Fixtures / Finishes:
  Total Cost = Quantity × Unit Cost

Budget:
  Difference   = Budgeted − Actual
  Balance Due  = Actual − Paid
  Category estimates linked to FF&E / Client Profile where applicable
  Summary totals and paid %

Dashboard:
  All KPIs are live COUNTIF / SUMIF / COUNTA / cross-sheet references

Invoices:
  Total, Total Paid, Outstanding

Reports:
  Room budget and vendor order reports pull live linked values

All formula cells are LOCKED + soft-blue styled.

27. CONDITIONAL FORMATTING
================================================================================
Status-based colors (search rules):
  GREEN  = Complete / Approved / Delivered / Installed / Paid /
           Good Condition / Yes
  YELLOW = Pending / In Progress / Sent / Client Review / Ordered /
           Shipped / Scheduled / Partially Paid / Waiting / Sourcing /
           Confirmed / In Production / In Transit
  RED    = Overdue / Delayed / Rejected / Damaged / Missing / Wrong /
           Backordered / Urgent
  GRAY   = Cancelled / On Hold / Not Started / Not Sent / Draft / Not Ordered

Numeric:
  Remaining budget / budget difference: red if < 0, green if >= 0
  To-Do due dates: red when overdue and not Complete

31. HOW TO START A NEW PROJECT
================================================================================
1. File → Save As → name for new client
2. Keep header rows; clear or overwrite sample data rows
3. Update 03 Client Profile first (gold cells)
4. Fill 04 Room List
5. Enter items on 05 Master FF&E (and/or 06–08)
6. Track budget, POs, approvals, delivery as project runs
7. Use 02 Dashboard for overview; print 21–25 for client/site packs


================================================================================
32. HOW TO CUSTOMIZE DROPDOWNS
================================================================================
1. Unprotect sheet if needed (password: premium)
2. Unhide "Lists" sheet (right-click any tab → Unhide)
3. Edit values in the relevant Lists column
4. Update data validation ranges on sheets if you add many new values
5. Re-protect sheets
